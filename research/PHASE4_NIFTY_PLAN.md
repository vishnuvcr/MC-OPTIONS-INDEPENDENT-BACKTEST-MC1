# Phase 4 — NIFTY

## Scope
Run the locked NIFTY BATMAN rule on the full option-data window available in the pinned dataset revision.

## Primary outputs
- eligible candidates
- gate-fail candidates
- executed trades
- gross and net P&L
- annual breakdown
- ES95 / ES99
- maximum drawdown
- data-gap/error table
- workflow artifact with raw trade-level output

## No optimization
No parameter search or rule adjustment is permitted in this phase.
